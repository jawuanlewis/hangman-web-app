## 🧠 Project Overview

The original source code for my own personal, web-based version of the game **_Hangman_**. This monolithic repo contained both the React frontend and Node.js/Express backend. It has since been refactored into two standalone repositories for better separation of concerns and independent deployment.

## 📦 Current Repositories

| Repository                                                      | Description                                           |
| --------------------------------------------------------------- | ----------------------------------------------------- |
| [hangman-client](https://github.com/jawuanlewis/hangman-client) | React frontend — UI, routing, and gameplay experience |
| [hangman-api](https://github.com/jawuanlewis/hangman-api)       | Express backend — REST API, game logic, and database  |

For setup instructions, tech stack details, and contribution info, please refer to the READMEs in those repositories.
